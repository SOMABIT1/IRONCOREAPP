# IRONCORE AI FITNESS - MVP frontend

## Archivos
- `index.html`: estructura semántica.
- `styles.css`: diseño responsive mobile-first.
- `app.js`: navegación, reglas de plan y persistencia LocalStorage.

## Ejecución
Por usar módulos JavaScript, abre una terminal en la carpeta y ejecuta uno de estos comandos:

```bash
python3 -m http.server 8080
```

Luego visita `http://localhost:8080`. También puedes usar la extensión Live Server de VS Code.

## Demostración
Pulsa **Explorar demostración** para cargar datos marcados como demostrativos. Para comenzar desde cero, pulsa **Crear mi plan**.

## Alcance y seguridad
- No hay backend ni se envían datos a servidores.
- No hay pagos reales.
- El chat y el análisis fotográfico son simulados.
- Las estimaciones nutricionales son educativas y no sustituyen atención profesional.
- Los datos se guardan en LocalStorage y pueden exportarse o eliminarse desde Perfil.
